# 自动填写答案规则（仅限非计分练习 / 自检题）

> 2026-11-21 按用户要求，把答题辅助从「只给参考答案」改为「自动填写答案」。范围仍严格限定**非计分练习 / 自检题**；计分作业、测验、考试一律零点击立即停止。本文件描述的能力**尚未在真实答题界面实跑确认**，按钮文案与 DOM 结构一律按 `site-notes.md` 的保守策略处理：只依赖可见文案，不依赖选择器，不编造站点特征。

## 一、定位

在刷课播放流程之外，按「一题一轮」自动完成非计分练习的作答：抄录题干与选项 → 推理出答案 → **点击选项 / 填入答案文本 / 点「下一题」推进** → 逐题验证。

- **会改变页面作答状态**，因此只限不计分、可反复的练习 / 自检题。
- **最终「交卷 / 提交成绩」按钮不点**，停在提交前交还用户本人确认。
- 不进入播放主循环；命中 `PRACTICE_QUESTION` 时暂停循环。

## 二、适用范围

| 类型 | 是否适用 | 处理 |
| --- | --- | --- |
| 明确标注「练习 / 自检 / 随堂练 / 不计分 / 不计入成绩 / 可反复作答」的题目 | 适用 | 逐题自动填写答案 |
| 计分作业、章节测验、单元测试、期中 / 期末考试 | 不适用 | `VERIFICATION`：立即停止、零点击、不给答案、不填写 |
| 章节树「测试」节点、polymas「训练题库」tab | 不适用 | 按 `site-notes.md` 既有结论视为考核类，不进入 |
| 验证码、人脸、摄像头抽检、风控提示 | 不适用 | `VERIFICATION`，立即停止 |
| **判不准是否计分** | 不适用 | 一律按 `VERIFICATION` 停止、零点击 |

> 判定原则：**宁可少填一题，不可放宽一次**。任何疑虑都归为计分考核。用户随时说「停」即立即停止。

## 三、计分判定表（只依据可见文案）

| 信号 | 归类 |
| --- | --- |
| 「不计分」「不计入成绩」「仅供练习」「自检」「随堂练」「可反复作答」「答错可重做」 | 倾向 `PRACTICE_QUESTION` |
| 「测试」「考试」「作业」「测验」「计分」「计入平时分」「限时」「仅一次提交机会」「提交后不可修改」「剩余次数 1」 | `VERIFICATION` |
| 两者同时出现，或都没有，或文案模糊 | `VERIFICATION` |

## 四、按钮语义表（决定哪些能点）

| 按钮 / 控件 | 能否点击 |
| --- | --- |
| 单选项、多选项、判断题的真 / 假、下拉选项 | 可点（填答案） |
| 文本输入框（填空 / 简答） | 可输入答案文本 |
| 「下一题」「确认」「检查答案」「提交本题」「查看解析」 | 可点（推进 / 校验，非最终交卷） |
| 「交卷」「提交试卷」「提交成绩」「完成并计分」 | **不可点**，停在提交前交还用户 |
| 验证码、人脸、摄像头、风控弹窗的任何按钮 | **不可点**，立即停止 |
| 认不出语义的按钮（含只写「提交」的） | **不可点**，按最严格处理并报告 |

> 按钮文案是**待验证候选**。只有截图中明确可辨的文案才按上表归类；语义含糊时视为最终交卷，不点。

## 五、工作流（一题一轮）

1. **触发与确认**：仅当用户显式请求（「自动填答案」「帮我填上」等）或主循环命中 `PRACTICE_QUESTION` 时启用；默认不启用。开始前用一句话向用户确认本次范围（哪门课 / 最多几题 / 不自动交卷）。
2. **判类**：按第三节确认「非计分」。命中计分特征或判不准 → `VERIFICATION`，零点击、不填、不给答案。
3. **取题（观察）**：先做 SKILL.md 第 0 步确认受控标签 → `dom_cua_get_visible_dom` + `tab_screenshot`；polymas 侧 DOM 不可用，一律以截图为准，**截图必须实际查看**。抄录题干、选项、按钮文案。
4. **求解**：用模型知识推理，或用 WebSearch / 公开资料检索核对教材与术语。**禁止**调用平台题库 / 搜题接口 / 答案 API、读取隐藏字段或页面源码里的答案、利用平台漏洞。把握程度为「低」时先向用户说明，不硬填。
5. **填写**：
   - 只用**最新一次**快照的 `node_id` / 坐标；界面变化后重新快照。
   - 智慧树侧优先 `dom_cua_click` 点 `node_id`；polymas 侧无可用 `node_id`，用截图 + `cua_click` 坐标。文本输入用 `dom_cua_type` / `cua_type`。
   - 一次只做一个动作，**点击后立即重新观察**，确认状态真的变了再进下一题；不重试可能已生效的动作，禁止连续盲点。
6. **记录**：每填一题在对话里报一次（题号 / 题干摘要 / 所填答案 / 把握程度）。
7. **收尾**：达到单轮题数上限、遇到「交卷 / 提交成绩」、题目做完，或用户说「停」→ 输出汇总，停在提交前，请用户本人确认提交；随后询问是否继续播放循环。

## 六、停止条件（任一命中即停）

- 出现计分 / 验证 / 风控特征，或判不准是否计分
- 出现「交卷 / 提交成绩」按钮
- 点击后界面连续两轮无变化（疑似被拦截）
- 题干或选项读不全、截图模糊、按钮语义认不出
- 达到单轮最多题数（默认 20）、用户说「停」、会话失效

## 七、禁止清单

- 点击「交卷 / 提交成绩 / 完成并计分」，或任何计分考核界面的任何按钮。
- 调用题库、搜题接口、答案 API 或平台任何写接口；读取 Cookie、Token、隐藏字段、页面源码里的答案。
- 随机选项、按提交率交卷、批量并发处理多道题、多账号操作。
- 替用户确认验证码 / 人脸 / 风控弹窗；关闭用户正在使用的窗口。
- 为「帮上忙」而放宽计分判定，或在判不准时继续填写。
- 把计分考核的答案写出来让用户在计分界面照填。

## 八、与其他状态的关系

| 状态 | 关系 |
| --- | --- |
| `VERIFICATION` | 优先级最高，零点击、不给答案、不填写 |
| `PRACTICE_QUESTION` | 暂停播放循环，转入本文件工作流 |
| `PLAYING` / `ENDED` / `ALL_DONE` / `EMPTY_COURSE` / `SESSION_EXPIRED` | 原有逻辑不变 |
| `UNKNOWN` | 不动作；连续达到上限即停止 |

## 九、台账

自动填写**不写入** `scripts/ledger.py`：台账只记录视频小节播放状态，练习题作答不属于进度事实，避免混淆。
