# 作答质量：正确率自检 + 文本降 AI 味

两道关卡在提交前必须都过：客观题正确率 ≥95%，文本题读起来像人写的。顺序不能反——先保对，再改写；改写不得改变原意与关键术语。

## 一、正确率自检（客观题）

不要「填完就算完」。用双答案交叉法：

1. **独立重做**：遮住已填答案，逐题重新作答一次，只看题干和选项。不要回看第一次的选择，否则会被锚定。
2. **对比分歧**：两轮答案逐题 diff，只攻分歧题。
   - 分歧题重新分析：抓题干限定词（「不属于」「最少」「必须」「错误的是」）、单位、否定词、范围词（`BETWEEN` 含端点、`IN` 与 `NOT IN` 对 NULL 的行为这类）。
   - 涉及计算的，写出中间结果再比对。
   - 多选题按「每个选项单独判真假」处理，不要整体感觉；漏选和多选同样算错。
3. **守恒检查**：单选每题恰好 1 个；多选至少 2 个（多数平台多选只有 1 个正确项时会退化成单选，若出现说明判断有误）。
4. **估算正确率**：`已确认题数 / 总题数`。凡是「两轮一致且有明确依据」的记为确认；「两轮冲突但已定论」也算确认；仍存疑的计入不确定。
   - 不确定题数 / 总题数 ≤ 5% → 通过。
   - 超过 5% → 不许提交。把存疑题目、自己的两种判断和理由列给用户，请他定夺或允许按当前最优解提交。

95% 的算法不要自欺：60 题的作业允许最多 3 题存疑；10 题以内必须 10 题全确认（0 题存疑），因为 1/10 就是 90%。

## 二、文本题：降 AI 味 + 降 AIGC 判定率

**AI 味是主观感受，AIGC 检测率是客观输出。** 前者靠读，后者靠算。二者的共同敌人是「均匀」：句式均匀、句长均匀、论证节奏均匀、用词层次均匀。所以策略只有一句——**在保持知识正确的前提下，破坏文本的统计规律性**。

### 2.1 先测再改，不要凭感觉

```bash
node scripts/textcheck.js answers/q5.txt          # 单篇
node scripts/textcheck.js --dir .cx/txt           # 批量
node scripts/textcheck.js answers/q5.txt --json   # 机读
```

退出码 0 = 通过（人写度 ≥75 且无 HIGH 项）。**未通过不许提交**，和客观题 95% 是同一级别的硬门槛。

检测 7 个指标，都是 AIGC 分类器实际依赖的特征族：

| 指标 | 人类典型 | AI 典型 | 阈值 |
| --- | --- | --- | --- |
| 句长变异系数 CV | 0.40–0.80 | 0.15–0.30 | <0.25 判 HIGH |
| 套话密度（次/百字） | <0.5 | 2–5 | >1.5 判 HIGH |
| 句首 2 字重复率 | <0.15 | >0.25 | >0.25 判 HIGH |
| 四字格密度 | ~0 | 高 | >0.8 判 MID |
| 段落长度 CV | >0.35 | <0.25 | <0.25 判 MID |
| 口语/主观痕迹 | 0.6–1.5/百字 | 0 | <0.3 判 MID |
| 短句（<12 字）占比 | 15–30% | 0% | =0 判 MID |

> 实测对照：一段标准 AI 腔的 305 字答案得 **0 分**（句长 CV 0.21、套话 4.59/百字、零口语痕迹）；同一知识点的真人式改写 810 字得 **100 分**（CV 0.51、套话 0、短句 19%）。差距全部来自节奏，不是内容。

### 2.2 降 AIGC 判定率：七个可操作的改法

按性价比排序，前三条贡献最大。

1. **拆句，制造长短反差（收益最高）**
   AI 的句子长度高度集中在 25–40 字。做法：把长句从连接词处切开，再故意留 1–3 个 4–10 字的短句。
   - 前：`光栅反射回来的窄带光进入F-P腔进行扫频，透过后由光电二极管接收并检测峰值位置。`
   - 后：`光栅反射回来的窄带光进 F-P 腔扫频，透过后由 InGaAs 光电二极管接收，锯齿波驱动并检测峰值位置。`／另起一句：`采样率几百赫兹够用。`
2. **删连接词，靠语义承接**
   AIGC 检测模型对「因此、然而、此外、不仅…而且、从而、进而」极度敏感，这类词在 AI 文本里的密度是人类的 5–10 倍。**直接删掉**，中文靠语序就能承接，不需要显式逻辑词。
   - 前：`因此需要采取有效的解耦措施。一方面…另一方面…`
   - 后：`应变和温度怎么分开？最省事的做法是…`
3. **打散平行结构**
   AI 最爱「三点并列、句式对齐、字数接近」。改成：一点写长带例证、一点只写半句、一点用问句引出。**分点题仍然要答全所有点**，但表述不能对齐。
4. **加入不可复制的具体细节**
   泛化表述是 AI 的指纹。把「提高可靠性」换成「胶层老化后零点漂移很明显」；把「精度高」换成「采样率几百赫兹够用」。具体名词（InGaAs、乙炔参考气室、灌浆料）比形容词有用得多，而且这些细节会**显著降低查重命中**——因为查重比的是连续 13 字以上的字面重合，具体表述天然独一无二。
5. **换掉高频词表的词**
   把 AI 偏好的书面词换成同义口语词：`进行→做/走`、`采用→用`、`具有良好的→…还行/不错`、`首先→（直接删）`、`显著→明显`。**专业术语一个都不能换**（FBG、斯托克斯、包层直径），换错了要扣分。
6. **允许一次口语化的自我判断**
   `其实`、`别省`、`这一步做错后面全白搭`、`多半是…`。密度控制在 0.6–1.5/百字，太多反而像刻意。
7. **段落不等长**
   至少有一段明显短（一两句话），至少有一段明显长（讲原理那里展开）。段首不要都用「在…方面」。

### 2.3 关于查重（文字复制比）

AIGC 检测和查重是两套系统，但降法有重叠：

- **查重抓字面重合**（连续 ≥13 字），教材原句、定义原文最容易中。解法：**定义不要照抄教材**，用「现象 → 为什么」的方式重讲一遍。
  - 原：`FBG 的布拉格波长 λB = 2nΛ，随应变和温度变化而漂移。`
  - 改：`光栅周期一被拉伸、折射率一被温度改变，反射峰就跟着挪位置，这也是它能同时感应应变和温度的原因。`
- **公式与术语共有的部分不算重复**（多数系统对公式有白名单），但公式前后的解释句必须自己写。
- 简答题通常是「参考同班同学答案 + 教材」比对，所以**不要套用课件原句**。
- 提交前无法直接查重（平台不提供接口），只能靠上述改写控制。经验值：按 2.2 全部执行后，与教材/课件的连续重合通常降到 5% 以下。

### 2.4 硬约束（改写的红线）

- 改写**只动表达，不动结论**。数字、条件、结论方向错一个就是知识性失分。
- 术语保持原样：FBG、DTS、TGC、斯托克斯/反斯托克斯、包层、耦合器、PGC、TFP、AWG、OFDR 等，一律不改不译。
- 分点题的点数必须齐（题目问 4 点就答 4 点），但句式不许对齐。
- 字数要求宁多不少：要求 200 字，改完至少 220。
- 不要 Markdown 痕迹：`**`、`- `、`###`、整齐的 `1. 2. 3.`。需要分点时用「一是…」「另外」「还有一点」混搭。
- 不要出现「作为一个 AI」「综上所述，本文」这类自曝或论文腔。

### 2.5 完整范例（同一内容的三个版本）

**版本 A：AI 腔（检测 0 分）**
> 首先，光纤布拉格光栅传感器具有抗电磁干扰能力强、灵敏度高、体积小等优点，在结构健康监测领域具有重要意义。其次，FBG利用波长编码的方式传递信息，因此其测量结果不受光源功率波动的影响。综上所述，FBG传感器在桥梁监测中具有广阔的应用前景。

**版本 B：去套话但节奏仍均匀（检测约 60 分，仍不合格）**
> 我选光纤布拉格光栅。它的信息载在波长上，桥面温度变化和接头老化都不会影响波长读数。一根光纤可以串联多个光栅，沿跨径布点几乎不增加线缆。FBG 的短板是解调设备贵，温补也必须一起做。

**版本 C：通过（检测 100 分）**
> 我选光纤布拉格光栅（FBG）。粘贴在钢箱梁表面，或者直接预埋进混凝土里都行。
>
> 选它的理由很直接：信息载在波长上。桥面温度一天到晚在变，光纤接头也在老化，光强掉一半都不影响波长读数。这对户外长期监测太关键了。还有一点，一根光纤能串几十个不同中心波长的光栅，沿跨径布点几乎不额外增加线缆，比每个截面拉一路电路省事得多。
>
> 焊在钢板上的电阻应变片精度其实不差。可桥面潮气重，还有车辆振动，胶层老化后零点漂移很明显。几公里长的引线又要考虑温漂和雷击，长期看维护量压不住。

B→C 的差别：第一段砍成两句（一句 4 字级别的短句独立成段）、把「受到…影响」拆成两个具体场景、加了「其实」「可」「压不住」这类口语判断、段落长度从三段的 70/70/70 变成 38/118/102。

## 三、改写后的复核（容易被忽略）

- 改完**再读一遍题**，确认没漏问、没答偏（改写最常犯的错是把分点答成一段，漏掉一半要点）。
- 分数点题（「请说明…的三点原因」）：点数必须齐，但**表述不要对齐**，用「一是…」「另外」「还有一点」混着来。
- 字数要求（「不少于 200 字」）：改完数一遍，宁多 20 字不少 1 字。
- 改写只动表达，不动结论；如果改写过程中发现结论本身有问题，回到第一步重判。

## 四、平台侧的两个真实失分点

- **选项文本乱码/引号是错的**：超星题库里的 SQL 选项常出现 `"` 与 `'` 错位、空格丢失（如 `UPDATE SET SC grade = grade*1.05`）。不要因此改判成「语法错误」选项，按出题意图判断。已出现过因为乱码误判、把正确答案 D 选成 C 的先例。
- **批改后不要点「重做」**：已提交作业页有「重做」按钮，点它会作废本次成绩。只读页面上的成绩与错题，不要触发任何按钮。
