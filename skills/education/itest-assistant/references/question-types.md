# 填空题族解法手册（选词 / 段落匹配 / 短文填词）

> 适用版式：一屏只显示一个空或一句陈述，下方一个「请输入答案…」输入框，右上进度 `1/10`、`7/10`，顶部有「答题卡」。
> 本手册只解决「**填什么**」；怎么截图读题、怎么点、怎么翻页仍按 `SKILL.md` 第 1–6 步执行。
> 判题前先读本文件，再按 `references/answer-quality.md` 做双答案交叉，最后跑 `scripts/answercheck.js` 做守恒校验。

## 0. 三条硬规则（最容易翻车的地方）

1. **先齐材料，再动笔**。一屏一空最容易诱使「做眼前这一空」。必须先把短文全文、词库全部 15 个词、段落 A–O 全部读完，整篇一次解完，再按屏幕题号逐屏填。选词填空一旦边填边猜，几乎必然出现同一个字母用两次。
2. **答案写成字母还是单词，看题干形态**：有词库（A–O 一列单词）→ 填字母；有段落标号（A/B/C…）→ 填段落字母；句内挖空且无词库 → 填一个单词（含必要的词形变化）。输入框示例、已答题的答案格式、题目说明三者不一致时，以题目说明为准，并把判断依据写进回报。
3. **编号是三层，不是一个数**。填错行多数来自把三者混为一谈：

| 层 | 例子 | 用途 |
|---|---|---|
| 文中空号 | `a five-mile __3__ trip`、`…minds. __17__` | 定位原文、写依据 |
| 屏幕题号 | 输入框上方 `3.`、`17.` | `answers.json` 的 key、`inputs` 的 `no` |
| 进度序号 | `1/10`、`7/10` | 只表示本组第几题，不是题号 |
| 答题卡题号 | 面板里另一套全局编号 | 跳题用，别拿来当答案编号 |

先建映射表：`屏幕题号 | 文中空号 | 答案 | 一句话依据`。截图里出现过「文中空号 3–12 / 进度 1/10」「屏幕题号 17 / 进度 7/10」这类错位，按文中空号推答案、按屏幕题号填输入框。

## 1. 选词填空（Banked Cloze，15 词选 10）

**识别**：页面一列 A–O 共 15 个备选词（按字母序排列，不是答案顺序）；短文里 10 个空；一屏一空。

### 解法流水线

1. **抄全材料**：全文逐句抄下（含首尾句），每个空前后各留 3–5 个词；词库 15 个词连字母一起抄。手机截图分多张时先拼成完整文本再开始。
2. **给词库打标签**：每个词标 `词性 + 形式 + 固定搭配`。重点标出同根不同形（`deposit / deposited`、`present / presented`、`crucial / crucially`、`regular / regularly`）——这类词词义几乎一样，只能靠句法定形。
3. **逐空定词性**（决定性一步，优先于词义）：

| 空前后形态 | 需要的词性 |
|---|---|
| `a/an + __ + n.` | 形容词 |
| `the + __ + of` / `his __ of` | 名词 |
| `be / was + __` | 形容词或过去分词 |
| `情态动词 + __` | 动词原形 |
| `介词 + __` | 名词 / 动名词 |
| `主语 + __ + 宾语` | 动词（看时态、单复数） |
| `动词 + __` 或句首修饰全句 | 副词 |
| `数词 + __ + n.` | 形容词或名词性修饰语 |

   产出表：`空号 | 需要词性 | 形式的额外约束（时态/单复数/被动） | 候选字母`。
4. **语义与搭配缩圈**：先抓固定搭配（`a school run`、`an oil check`、`drop sb off`、`be reunited with`、`a range of`、`be crucial to`、`Following a … by …`），再看语义场（受惊的猫 → 轻轻推、卡住、救援），最后核对时态语态、主谓一致、冠词（`an` 后面必须是元音开头）。
5. **全局唯一性**：10 个空通常用 10 个**不同**字母。先做候选最少的空，锁定后从词库划掉；最后剩下的 5 个词必须能说明为什么没用（词性不符 / 语义不符 / 已被同根词占位）。若题目说明允许重复，才允许重复。
6. **回填通读**：把选中的词代回全文读一遍，检查有没有被跨行定语从句、插入语、并列结构骗到。

### 两轮交叉

- 第一轮：按空号 1→10 顺序做。
- 第二轮：遮住第一轮答案，按**词库字母顺序 A→O** 反推「这个词最适合哪个空」。
- 只攻两轮不一致的空，重判时回到第 3 步的词性判定，不要凭语感改。详见 `references/answer-quality.md` 第一节。

### 高频失分点

- 词库按字母序排列 ≠ 答案顺序，不要顺着 A→O 硬塞。
- 只看紧邻两个词判词性会错：修饰语常跨行、跨逗号。
- 专有名词、数字、比较级是定位锚，不是要填的词。
- 平台若要求填**单词**而非字母，填词库里的**原形**（`deposited` 就照抄 `deposited`），不要自行变形。

## 2. 段落信息匹配（Matching，答案填段落字母）

**识别**：全文若干段以 `A.` `B.` `C.`… 标字母；题干是一句完整陈述，句末跟一个 `__17__`；一屏一句；输入框填**一个字母**。注意看题目说明有没有 `You may choose a paragraph more than once` / `NB` 提示。

### 解法流水线

1. **先给每段写摘要**：通读全文，给 A–O 每段写 8–15 字中文主旨，列成表。**不要边读题干边找词**，否则会被第一处原词命中带偏。
2. **提取题干锚点**，按可靠度排序：专有名词 / 数字（Queens、Skillman Ave、116 parking spots、12 percent、40 percent）> 极端词与否定（`not help much`、`only`、`never`、`most`）> 抽象概念（`culture war`、`mindset shift`、`data`）> 因果转折（`but`、`however`、`because`）。
3. **预判同义转述**：题干很少照抄原文。把锚点映射成原文可能说法：`data → figures / studies / evidence / sales data`；`changing minds → persuade / convince / admit / believe`；`war of culture → culture wars / divide / pushback is cultural`。
4. **定位再确认**：用锚点扫出 1–2 个候选段，再读候选段的**首句、末句、转折句**，确认整句结论落在这一段，而不是只出现了一个词。
5. **二轮排除**：把 10 句答案按段落汇总。若说明「每段只用一次」，出现重复必须重判；若允许重复，重复段必须有两句各自独立的明确对应。再检查完全没被用到的段落是不是其实更贴合某题。
6. **反向交叉**：第一轮「题干 → 段落」，第二轮「段落 → 哪句题干」，diff 只攻分歧题。

### 高频失分点

- **原词重现常是干扰**：题干照抄某段一个细节词，但结论在另一段。命中词只是入口，不是答案。
- 段落首末句是主旨，细节题可能落在段中；只看到锚词就选会错。
- 否定和比较方向必须对齐：`does not help much` 对应 `isn't much good at`；方向反了就是另一段。
- 跨段落信息拼成的题干，通常对应「综合论述」那一段，不是出现词最多的那一段。
- 数字题：题干数字与原文数字对不上，多半另有所属。

## 3. 短文 / 听写填词（无词库，填一个单词）

**识别**：短文里挖 10 个空（常从 `__3__` 编到 `__12__`），上方可能有「点击开始播放」音频条，输入框 `请输入答案…`，无词库、无选项。

### 解法流水线

1. 先按上下文把 10 个空全部推一遍：固定搭配 > 语法形态 > 语义场。例子：`a five-mile __ trip` → 往返 `round`；`on a school __` → `run`；`do an __ check` → `oil`（`an` 要求元音开头）；`drop his grandson __ at school` → `off`；`was "__ for me to come have a look"` → `shouting`；`I __ pushed it` → 副词 `gently`；`It __ even further into the engine` → 过去式 `reversed`；`and was __` → 过去分词 `stuck`；`Following a __ by …` → 名词 `rescue`；`was later __ with its owner` → `reunited`。
2. **词形是主要失分点**：写答案前逐个问「这里要原形 / 过去式 / 过去分词 / 现在分词 / 复数 / 副词吗」。空在 `was` 后、`has` 后、`a` 后，答案形态完全不同。
3. **音频只做校对，不代替推断**：若页面有播放按钮且属训练卷，按 `references/audio-capture.md` 回环录制 → 转写 → 用逐字稿校对 10 个词（尤其专有名词、数字、连读处）。转写没听清的空按上下文推断，并标「待音频确认」。正式考试按安全边界直接拒绝录音。
4. **只填那一个词**：不加冠词、不加标点、不加序号、不写中文；大小写按原文（句首不大写也照抄）。若平台要求首字母大写或整词小写，按已答题的格式统一。

## 4. 守恒校验（提交前的机械关）

写一份 `check.json` 后跑：

```bash
node scripts/answercheck.js check.json
```

三种 `type`：

```json
{ "type": "banked", "bank": {"A":"approximately","B":"case"}, "blanks": 10,
  "answers": {"1":"C","2":"N"}, "allowReuse": false }
```

```json
{ "type": "matching", "paragraphs": 15, "questions": 10,
  "answers": {"11":"E","17":"L"}, "allowReuse": false }
```

```json
{ "type": "blank", "blanks": 10,
  "answers": {"3":"round","4":"run"}, "allowReuse": false }
```

脚本检查：答案数量、字母是否越界、是否重复、`blank` 类型是否为单个词、题号是否连续缺号，并打印未使用的词/段落作为干扰项核对。退出码 0 才继续填答。**脚本只查形式，不查对错**；正确率仍靠双答案交叉。

## 5. 答案输出格式

回报时给一张表，不贴原始 JSON：

| 屏幕题号 | 文中空号 | 答案 | 依据（一句话） | 置信 |
|---|---|---|---|---|
| 1 | 1 | C | 该空需名词，`chance` 与「want as many choices」语义呼应 | 确定 |
| 17 | 17 | L | L 段 `data isn't much good at changing minds` 与题干同义 | 确定 |

- 存疑题单独列在表后，写清两种判断与理由，交用户定夺，不硬猜。
- 桌面自动化时把答案写进 `answers.json`（`type` 用 `banked` / `matching` / `blank`），`screen.json` 的 `inputs[].no` 用**屏幕题号**；填完按 `SKILL.md` 第 5 步逐屏截图复核。
- 若题目来自截图而非浏览器页面，判题流程完全相同，答案交用户手填；不引入额外的设备操控链路。

## 6. 校准样例（2025 年 12 月 CET-4 第一套，与三张截图同源）

> 用途：**自检方法是否走对**，不表示新卷可以直接套答案。新卷必须按第 1–3 节重做一遍。

| 题型 | 材料 | 标准答案 | 检验点 |
|---|---|---|---|
| 选词填空 | `People tend to want as many choices as possible…`，词库 A–O | 1–10：C N D H J E I O G K | 10 个字母互不重复；剩 A/B/F/L/M 五词全是词性或语义不符 |
| 段落信息匹配 | `The battle over bike lanes needs a mindset shift`，A–O 共 15 段 | 10 句：E K C O G / D L J A H（其中屏幕题号 17 对应第 42 句 → **L**） | 题干 `In a war of culture, data does not help much in changing people's minds.` 只与 L 段 `If we've learned anything about culture wars, it's that data isn't much good at changing minds.` 对应；靠 `culture wars / data / changing minds` 三锚点定位，不是靠 `war` 单词命中 |
| 短文填词 | `A terrified cat has survived a five-mile …`，空 3–12 | round / run / oil / off / shouting / gently / reversed / stuck / rescue / reunited | 全部是搭配 + 词形题；`an __` 定元音、`was __` 定分词、引号内 `was "__ …"` 定现在分词 |

三张截图属于同一套真题的三个不同部分，**屏幕题号与真题卷面题号不一致**：截图里的 `17.`（进度 7/10）对应该套真题第 42 题（Section B 的 36–45 被重编号为 11–20）；`1.`（进度 1/10）是 Section A 的第 1 空；短文填词那屏题号 `3.` 但进度仍是 `1/10`。映射表是必备项，不能拿进度或卷面题号直接当输入框编号。

## 7. 速查

- 有词库 → 字母；有段落字母 → 字母；句内空无词库 → 单词。
- 一屏一空 → 整篇一次解完再逐屏填，绝不边看边猜。
- 空号 / 屏幕题号 / 进度 / 答题卡题号 → 先建映射表。
- 定词性优先于定词义；同根不同形靠句法。
- 填前跑 `answercheck.js`，填后逐屏截图复核。
- 拿不准就标存疑，别用「差不多」补满 10 个空。
