# iTEST 页面地图、实测坐标与踩坑记录

> 桌面操控路线。**2026-11-21 用真实试卷（四级听力模拟题）完成首次标定**。
> 所有坐标单位：物理像素，坐标系 2560×1600，Edge 最大化且位于 (0,0)，Windows 150% 缩放。

## 一、坐标系（重要，先读这条）

`act.ps1` 现在输出 **2560×1600 物理像素**，与 `shot` 截出的 PNG 一一对应：
**截图上量到的 (x,y)，直接喂给 `click --x --y` 即可，不做任何换算。**

取得这个一致性的前提有三条，缺一条就会点偏：

1. **`act.ps1` 必须是 UTF-8 带 BOM 保存**。Windows PowerShell 5.1 在中文系统下按 GBK 读无 BOM 的 `.ps1`，中文注释/字符串被打散，`Add-Type` 的 C# 代码跟着解析失败 → 整个动作层返回 `{}`。
   - 现象：`run.sh info` 报 `动作失败：{}`。
   - 修复：用 PowerShell 转码，不要用普通文本编辑器另存。
2. **脚本内部必须调 `SetThreadDpiAwarenessContext(-4)`**。从 node 启动的 powershell 继承的是 DPI-unaware，只有强制线程上下文才拿到物理像素。
3. **窗口必须最大化、贴 (0,0)、不被遮挡**。窗口一移动，所有坐标作废。

> 旧版文档写的「截图 1707×1067、不要 ×1.5」是 BOM 缺失时的错误状态，已废弃。

## 三、答题页版式（听力卷实测）

- 顶部左：iTEST logo、姓名、学号、「答题卡」按钮、「Listening…」下拉、「Section A」。
- 顶部中：**计时条有两种形态，每卷必须读图重新判定，不得沿用上一卷结论**：
  - 无限时训练卷：**正向计时**（从 `00:00:00` 往上走）。本次标定用的「四级听力模拟题（三）」即此形态，页面写「不限制考试时长」，无自动交卷风险。
  - 限时周测：**倒计时**（`剩余时间 44:58` 一类递减数字，一般是整卷一个总时钟）。**归零自动交卷、不可撤销、未答题直接空白**；作业性质，不带监考 / 考试码 / 抓拍，`guard` 不会拦截，所以必须自己做时间预算。
  - 读不清 / 被遮挡 / 没有计时条 → 一律按限时保守处理，重新截图确认。
  - 判定后把结果写进 `screen.json` 的 `timer` 字段，用 `clock --screen` 落盘，每屏开头跑 `budget` 看 `[MODE=...]`。完整口径见 `references/timed-mode.md`。
- 顶部右：**「交卷」绿色按钮 @ (1965, 135)** —— 红线，只记录不点。
- 正文：Section 说明 + 「▶ 点击开始听力考试」条 @ (1232, 319) + 题目。
- 一屏固定显示 **2 题**（题号 1、2 或 3、4 …），布局完全一致。
- 底部：「上一题」@ (1825, 1401)、「下一题」@ (1922, 1401)。

## 四、关键结论：「下一题」按钮不可靠

实测连续点击「下一题」4 次（(1922,1401)，窗口已聚焦、页面已加载、听力播放前后都试过），**页面均无变化**；而答题卡点题号 100% 生效。

- **导航请用答题卡跳题，不要依赖「下一题」。**
- UIA 里也读不到「下一题」按钮（它是无名元素，被 `uia.ps1` 的空名过滤掉了）。
- 听力播放中（顶部蓝条「听力考试正在进行」）页面会锁定在音频对应题，此时点选项容易点错题 —— **播放期间只观察，不操作**。

## 五、无障碍树（UIA）什么时候可信

`uia.ps1` 读到的 `BoundingRectangle` 受调用进程 DPI 上下文影响：

- ✅ **窗口最大化、贴 (0,0) 时准确**：实测第 3 题 A 圆点 UIA 给 (669,489)，截图实测 (673,495)，差 4px，可用来交叉校验。
- ❌ **窗口非最大化/被移动/跨屏时不可信**：曾出现 x 差 300+、甚至负坐标。
- ❌ 读不到无名元素（「下一题」「开始考试」这类纯样式按钮）。
- ❌ 读不到 Canvas / 图片里的文字。

**用法**：窗口最大化后再跑 UIA 做**文字校对**和**坐标交叉验证**；最终点击坐标以截图为准。

## 六、题型与支持度

| 题型 | 页面形态 | 自动作答 | 说明 |
| --- | --- | --- | --- |
| 单项选择 | 题干 + A/B/C/D 圆点（原生 radio） | ✅ 已验证 | 点圆点或整行 |
| 多项选择 | 方框 | ✅ | 每个选项单独点 |
| 判断 | T/F 两项 | ✅ | 同上 |
| 选词填空（15 选 10） | 词库 A–O + 一屏一空 + 「请输入答案」框 | ✅ | 填**字母**；解法见 `references/question-types.md`；整篇一次解完，文中空号 ≠ 屏幕题号 |
| 段落信息匹配 | 段落 A–O + 一屏一句 + 句末空 | ✅ | 填**段落字母**；靠锚点定位而非原词命中；同上手册 |
| 短文 / 听写填词 | 短文 10 个空 + 输入框，可带播放条 | ✅ | 填**一个单词**并核对词形；有音频时用逐字稿校对；同上手册 |
| 阅读 | 一屏一篇 + 2–5 题 | ✅ | 先滚动读完再答 |
| 翻译 / 写作 | textarea | ✅ | 走文本关，粘贴不逐字敲 |
| 听力 | 「点击开始听力考试」、按 Section 播放 | ⚠️ 只填不听 | 模型听不到音频；听到什么由用户判断，助手只能按给定答案填 |
| 口语 | 准备/作答倒计时 + 录音 | ❌ | 不支持 |

填空题族（上表三种）共用一份判题手册 `references/question-types.md`：先收齐全篇材料、建 `屏幕题号 | 文中空号 | 答案 | 依据` 映射、定词性优先于定词义、两轮交叉、再用 `scripts/answercheck.js` 校验数量与重复。`inputs[].no` 一律用屏幕题号，进度 `1/10` 不是题号。

## 七、平台行为

- 作答页有**切屏监测**，会记录并报告。**不要**在考试中重启浏览器或频繁切窗口。
- 系统**每 60 秒自动保存**；断网重进可续答，已播完的听力不能重播。
- **限时卷倒计时归零会自动交卷**，不可撤销、未答题直接空白；这类周测不带监考特征，`guard` 不会拦截，所以必须按 `timed-mode.md` 做时间预算与保底填满。
- 正向计时（无限时训练卷）无自动交卷风险。两种形态**每卷读图重判**，不能沿用上一卷。
- 交卷后**不能再次作答**。训练卷可重做，正式考试不可。
- 「考试尚未结束，无法查看成绩」= 已交卷但考试窗口未关，不是失败。

## 八、其他坑

- **截图截的是屏幕**：WorkBuddy 盖住 iTEST 时截到的是 WorkBuddy。先 `activate`。
- **截图不含鼠标光标**，不要靠找光标判断位置。
- **首次点击只激活窗口**：窗口未聚焦时第一下点击可能不触发控件，需要再点一次。
- **粘贴会覆盖**：`fill` 文本题先 `ctrl+a` 再粘贴。
- **不要点「重做 / 重新考试」**：会作废已交成绩。
- **ps1 改动后必须复查 BOM**：`Edit` 会保留 BOM，但用 `Write` 重写整个文件不会带 BOM，写完必须转码并跑一次 `run.sh info` 验证。

## 十、全卷实战记录（2026-11-21 上午，25 题全做完，未交卷）

### 听力是按 Section 分段播放的（重要）

- 音频条只有一个按钮「点击开始听力考试」，**它只播放当前 Section 的音频**，播完就停在原地，蓝色条变回「点击开始听力考试」，**不会自动进入下一个 Section**。
- 要点第二次时如果顶部标签还是 `Section A`，**会从 Section A 第 1 题重播**（实测踩到，白录 7 分钟）。
- 正确做法：先用答题卡点下一个 Section 的题号（如 8 或 16），顶部标签变成 `Section B` / `Section C` 后，再点「点击开始听力考试」。
- 三个 Section 的播放时长参考：A ≈ 7 分钟、B ≈ 9 分钟、C ≈ 10 分钟。整卷约 26 分钟音频，加上操作间隔实测 41 分钟。
- 播放顺序：Section A → B → C，每个 Section 内部题目按顺序自动推进，页面会跟着滚动。**播完的 Section 不能重播**。

### 窗口焦点被抢（本次最大的时间黑洞）

- WorkBuddy 自己也是置顶窗口，**每执行一条命令就会把自己刷到最前**，把 Edge 压下去。表现：`info` 报前台是 Edge，但截图截到的是 WorkBuddy；此时点击也会落到 WorkBuddy 上。
- `activate` 里的 `SetForegroundWindow` 被 Windows 前台锁拦下，`alt+tab` 也抢不过。
- 解法：动作层新增两条命令。
  - `topmost --title 试题作答`：`SetWindowPos(HWND_TOPMOST)` 把 Edge 顶到最上。**每条命令开头都加一次**。
  - `minimize --title WorkBuddy`：把 WorkBuddy 最小化（`--front` 会最小化当前前台窗口，**危险**——Edge 在前台时会把 Edge 自己最小化，实测踩过）。
- 踩坑记录：双击标题栏在「已最大化」状态下会把窗口**还原**；`win+up` 在已最大化时会弹「贴靠助手」。最大化前先看窗口是不是已经满了。

### 页面缩放会在操作中途变化

实测中途页面内容整体变小（顶部栏变高、字号变小），答题卡格子坐标随之改变。**任何坐标都不能跨轮复用**，每轮先用 `uia` 重取。
