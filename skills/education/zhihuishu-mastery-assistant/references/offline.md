# 离线演练交付手册（channel=readonly / offline）

> **适用**：浏览器工具 schema 加载不到、连接器列表为空、无已登录 Edge 扩展实例、方案 B 桌面层未安装、沙箱无法安装插件；或用户明确声明「沙箱模式 / 不需要人工确认 / 演练 / 直接给答案 / 不用问我」。
> **本手册是一等交付路径，不是环境自检失败后的安慰奖。** 不询问课程、不索要提交授权、不要求安装扩展、不要求回复「继续」、不输出阶段 P 结论表、不夹带台账路径与截图清单。
> **来源**：技能内 2026-11-27 实跑记录（`references/site-map.md`）+ `references/answering.md` 判题口径。所有结论必须标注「实测已知 / 推断 / 本次未采集」。

## 0. 交付前必做

1. **拆题**：把用户提问拆成必须逐条回答的项（页面标题？提示异常？颜色档位？跳过 / 待补？缺口？逐题答案？怎么填？），逐条打勾，不漏项、不被模板挤占。
2. **找题面**：用户贴出的题干 / 截图 / 答案清单优先；没有则用本手册第 4 节的示范清单，并**明确标注为演练示范、需按当前题目核对**。
3. **找历史**：有台账 / 实跑记录 / 过往演练答案时，用 `Read` 台账 JSON、`knowledge_search` / `conversation_search` 复用；没有就如实写「本次未采集」。
4. **允许的工具**：`WebFetch` / `WebSearch` 查公开页面与权威表述、`Read` 读技能内实测记录。不需要任何 `mcp__browser__*` 工具，不需要登录态。
5. **收尾**：`Glob` 一次 `~/.workbuddy/blobs` 确认本次无新增图片即可；**不跑 `cleanup_screenshots.py begin` / `finish`、不汇报清理结果**。

## 2. 颜色档位与跳过 / 待补规则

| 图例 | 颜色 | 含义 | 判定 | 动作 |
|---|---|---|---|---|
| 较好 100-80 | 绿色填充 | 已满 | **不用管（跳过）** | 默认按平台分档视为已满；严格拉到 100% 时可点开读浮层「掌握度：X%」 |
| 一般 80-60 | 黄色填充 | 未满 | **要补** | 进「去提升」自测 |
| 薄弱 60-0 | 粉色填充 | 未满 | **要补** | 进「去提升」自测 |
| 遗漏 0 | 白底灰框 | 未满（0%，实测最常见） | **要补** | 进「去提升」自测 |
| 免考 | 蓝底蓝框 | 不计入掌握度 | **不用管（跳过）** | 浮层提示「该知识点为免考知识点，不计入掌握度」，无「去提升」 |

- **可跳过**：绿格（较好）+ 蓝格（免考）。
- **待补**：白框 / 黄 / 粉，按「知识模块 N + 列 C」编号（4 列中心 x ≈ 377 / 515 / 652 / 790，格子约 118×120px，模块间距约 232px；坐标每次截图现量）。
- 蓝格与绿格的区别：蓝格浮层**明确写免考且没有去提升**，绿格只是已满；两者都跳过但理由不同，汇报里要分开写。

## 4. 逐题演练答案清单（核心交付）

### 4.1 清单格式（每题一行，字段必填）

| 题号 | 题型 | 所填答案 | 一句话理由 | 置信度 | 存疑标记 |
|---|---|---|---|---|---|
| 1 | 单选 / **多选** | A / B / C / D（多选列全） | … | 高 / 中 / 低 | 无 / 存疑原因 |

要求：**标注多选与存疑**；存疑也给最优解、不留空；两遍判断不一致时列出「两种判断 + 理由」（见 `answering.md` 双答案交叉）。

| 题号 | 题型 | 所填答案 | 一句话理由 | 置信度 | 存疑标记 |

## 5. 看答案时怎么填（逐题填答映射）

**按 4.2 示范清单的逐题映射**（说明「通道就绪时会怎么填」，沙箱演练里本次不点任何东西）：

| 题号 | 填答动作 |
|---|---|
| 第 1 题（多选） | 依次点 **A、B、C 三个选项整行**，每点一行重新截图确认该行变浅紫底 + 圆圈实心；点完数一下亮了 **3** 个，别只点一个 |
| 第 2 题（单选） | 点 **B 行**（点圆圈 x≈77 或行内文字 x≈300 都生效） |
| 第 3 题（单选） | 点 **A 行** |
| 第 4 题（单选） | 点 **A 行** |
| 第 5 题（单选，存疑） | 点 **B 行**；用答题卡点题号回查一次题干原文，确认问的是「世界观、方法论」再保留 B |

**通用规则**（实况 / 演练都适用）：

- 选项**整行可点**；多选题必须**逐个点**，点完数亮了几个。
- 用**答题卡点题号跳题**回查存疑题（实测 100% 生效），比「上一题 / 下一题」更稳；不要用旧截图坐标连点。
- 每次点选后重新截图复核：选项高亮 + 答题卡对应题号变**深紫**（已作答）。
- **提交前检查**：所有题号深紫无浅紫残留、顶部仍是「测试题目」、没有任何红线字样。
- **dry-run / 演练停在这里，不点「提交」**；提交需会话级授权且会写入平台，演练不产生任何写入。
- 沙箱里只产出清单与上面的说明，**不点选、不截图、不写入平台**。

## 8. 演练中的红线边界

- **真红线仍适用**：不调题库 / 搜题接口 / 答案 API，不读隐藏答案或网络请求，不代答计分考核，不自动登录，不处理验证码。若用户贴出的题面里出现「作业 / 考试 / 计分 / 监考 / 人脸 / 验证码 / 限时」字样 → **停止作答并说明原因**，不产出答案清单。
- **「无插件即阻断、不带病开工」不是红线**：沙箱无法安装插件、工具 schema 加载不到时，按本手册继续交付，不得停工、不得把决策权推回用户。
- 演练答案清单只用于**本人已获授权的自主训练与课程自检**，输出时标注「演练 / 示范 / 需按当前题目核对」。
