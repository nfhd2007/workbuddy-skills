# 自测题判题与提交手册

> 适用范围：**仅**「掌握度分析 → 热力图未满格子 → 去提升」链路里平台自带的自测题（顶部标「测试题目」）。作业、测验、考试、计分考核一律不适用；判不准按 `VERIFICATION` 停止，零点击。

## 硬规则

1. **只依据可见截图读题**。本链路 DOM 快照只有 1 个节点，不能靠选择器、不能读隐藏字段、不能读源码或网络请求里的答案。
2. **不调用题库 / 搜题接口 / 答案 API**。答案来自模型推理，必要时用 `WebSearch` 核对公开权威资料（教材表述、官方文件）。
3. **不自动跨过红线**：答题浮层出现「计分 / 计入平时分 / 作业 / 考试 / 测验 / 限时 / 仅一次提交机会 / 考试码 / 监考 / 人脸识别 / 摄像头 / 抓拍 / 验证码」任一字样 → 立即停止、零点击、报告。
4. **提交必须有一项会话级授权**（阶段 0 已确认）。dry-run 模式下完成读题与点选后停在提交前，输出答案清单，掌握度不变。
5. **每步重新观察**：只用最新一次截图的坐标；界面变化后重新截图，禁止凭记忆坐标连点。

## 界面结构与读数

| 区域 | 读什么 |
|---|---|
| 顶部 | 知识点全名、「测试题目」标签（确认是自测而非作业考试） |
| 右上 | 「提交 ↗」按钮、`×` 关闭 |
| 中部左上 | 题型标签：`单选题` / `多选题`（紫色小胶囊） |
| 中部 | 题干「N、…」与 A–D 四个选项整行 |
| 右侧 | 「答题卡」→「客观题」→ 题号方块 1–N；图例「已作答（深紫）/ 未作答（浅紫）」 |
| 底部 | 「上一题」「下一题」 |

**题量以当次答题卡为准**（实测一套 5 题：1 多选 + 4 单选），不要假设恒为 5。

## 逐题工作流

### 1. 取题

- 先 `tabs_list` 确认受控标签还在，不在则重新 `user_open_tabs` + `tabs_claim`。
- `tab_screenshot` 一屏一题，实际看图抄录：题号、题型、题干全文、A–D 选项全文。
- 截图模糊、题干被截断、选项缺失 → **不作答**，报告「信息不完整」，不猜题、不盲点。
- 用「下一题」或**答题卡点题号**推进；实测答题卡跳题 100% 生效，优先用它回查存疑题。

### 2. 判题（双答案交叉）

1. **第一遍**：按题干语义与学科知识直接推一版答案，记录一句话理由。
2. **第二遍**：换一个角度复核——
   - 概念题：核对官方表述 / 教材原句（可用 `WebSearch` 查权威站点）。
   - 多选题：逐项判断「该选项是否同时满足题干所有空 / 所有限定」，不要因为「看起来政治正确」就全选。
   - 排除法：先删明显错项，再在剩余项里比较。
3. 两遍一致 → 高置信；不一致 → 标为**存疑题**，选更稳妥的一版，并在汇总里列出「题号 + 所填答案 + 两种判断 + 理由」。
4. **不留空**：存疑也要给最优解，不能因为没把握就跳过（提交前答题卡必须全部「已作答」）。

> 实测校准样例见 `references/site-map.md`「实测样题」表。它只用于校准读题口径，**不是题库**；不同课程 / 知识点题目不同，必须逐题现读现判。

### 3. 点选

- 选项**整行可点**：点圆圈（x≈77）或行内文字（x≈300）都生效；选中行变浅紫底、圆圈变实心。
- **多选题逐个点**，不要只点一个；点完截图数一下亮了几个。
- 题干单行时 A–D 中心 y ≈ 292 / 352 / 410 / 467；题干两行时 y ≈ 317 / 377 / 435 / 493。**以当前截图现量为准**。
- 用 `cua_execute` 批量点选可省调用，但最后必须单独 `tab_screenshot` 复核（内嵌截图可能拍到动画中间态）。
- 每次点选后看右侧答题卡：对应题号变深紫才算「已作答」。

### 4. 提交前检查

- 答题卡 **全部题号深紫**；没有浅紫残留。
- 逐题回看（或用答题卡跳题）确认勾选项与判题结论一致。
- 再确认一次顶部仍是「测试题目」、没有出现任何红线字样。
- dry-run → 在此输出答案清单并停止，不点「提交」。

### 5. 提交

- 点右上「提交 ↗」。**只点一次**；提交是异步的，若截图仍是题目，再单独截一张图，不要连点。
- 若弹出确认层，读清文案：确认是本自测的提交才继续；出现「作业 / 考试 / 计分 / 成绩」字样立即停。
- 提交后必须进入结果页；没进结果页就归 `UNKNOWN`，停下报告，不重试提交。

### 6. 结果页校验与纠错回路

结果页读三项：**掌握度 X%**、**总题数 N**、**已答对 M**。

| 情况 | 动作 |
|---|---|
| `M == N` 且 100% | 标记 `done`，记录 `final_pct=100` |
| `M < N` | 点「查看作答记录与解析」读正确选项 → 返回重做该知识点；**最多 2 轮** |
| 2 轮后仍不全对 | 标记 `partial`，在汇总列明题号与两种判断，不反复盲刷 |
| 结果页读不清 / 无结果页 | 标记 `unverified`，停下报告，不重复提交 |

- 纠错时只用结果页可见的解析文字，不猜、不调接口。
- 点结果页左上返回箭头 → 回到分析页顶部；**截图读基本信息**，确认「遗漏点数量」减少、平均掌握度上升。数据没变 → `unverified`，停下报告。

## 按钮语义表（认不出就不点）

| 文案 | 归类 | 动作 |
|---|---|---|
| 去提升（格子浮层） | 进入自测 | 允许 |
| 上一题 / 下一题 | 推进 | 允许 |
| 答题卡题号 | 跳题 | 允许 |
| A–D 选项整行 | 作答 | 允许 |
| 提交（测试题目浮层） | **写入掌握度** | 需会话级授权；dry-run 不点 |
| 查看作答记录与解析 | 只读纠错 | 允许 |
| 返回箭头（结果页） | 回分析页 | 允许 |
| 交卷 / 提交成绩 / 确认提交（作业考试） | 考核类 | **禁止** |
| 作业考试 / 训练题库 / 测试（章节树节点） | 考核类 | **不进入** |
| 关闭 `×`（答题浮层） | 放弃本次 | 仅在用户要求停止时点 |

## 停止条件

- 用户说「停」→ 立即停止，交还控制权。
- 命中任一红线特征 → 零点击停止。
- 连续 3 题读不清 / 3 个知识点 `UNKNOWN` → 停止报告。
- 连续 2 次提交后基本信息无变化 → 停止（疑似风控或网络异常）。
- 达到单次上限（默认 30 个知识点 / 60 分钟）→ 停止并输出汇总。

## 回报

每个知识点回报：知识点名、题量、答对数、最终掌握度、存疑题清单、是否触发纠错。不要贴原始 JSON 或坐标。
