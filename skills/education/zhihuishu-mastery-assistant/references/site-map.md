# 页面地图与实测记录（知到/智慧树掌握度链路）

> 全部结论来自 2026-11-27 在用户已登录的 **Microsoft Edge（WorkBuddy Edge 扩展程序，`browser_id=2`、`type=extension`、`family=edge`、`capabilities` 含 `user_tabs`）** 上的实跑。基准视口 **1699×888 CSS 像素**，对应扩展接管的用户 Edge 窗口。坐标仅作参考，**每次截图现量**；换分辨率、换浏览器通道（尤其降级到内置 IAB）时全部基准坐标作废，必须重新现量。
> 内置 IAB（`browser_id=1`、`type=desktop`）不共享登录态且没有 `user_tabs`，本技能默认不用；实例识别与选择口径见 `references/tooling.md`。
> 严格区分「实测确认」与「推断」：未实跑的界面按 `UNKNOWN` 停下，不套用旧文案盲点。

### 格子浮层

- 点未满格子 → 白色浮层（约 250×190px，出现在格子附近）：知识点全名、`掌握度：X%`、紫色「**去提升 >**」按钮（实测约 `(634, 434)`）。
- 点免考格子 → 浮层只有「该知识点为免考知识点，不计入掌握度」，**无去提升**。
- 浮层有淡入动画（约 200–300ms）：`cua_execute` 内嵌截图常拍到半透明中间态，**再单独 `tab_screenshot` 一次**。
- 浮层会遮住右侧相邻格子；切换格子前先点远处空白或换一列，避免点到浮层内部。

## 第 5 页：自测题浮层（点「去提升」后）

- **不是新标签**，是覆盖分析页的浮层；点「去提升」后浮层先淡出，需再截一张图才看到答题界面。
- 顶部：知识点名（如「习近平新时代中国特色社会主义思想主要包含哪些内容」）+「测试题目」标签；右上紫色「提交 ↗」（约 `(1528, 115)`）+ 灰色 `×`。
- 中部：题型标签（单选题 / 多选题，紫色小胶囊）、题干「N、…」、A–D 选项整行（点击整行或圆圈都生效，选中行变浅紫底 + 圆圈变实心）。
- 右侧「答题卡」：标题「客观题」、题号方块 1–N（实测 5）、图例「已作答（深紫）/ 未作答（浅紫）」。**点题号跳题 100% 生效**。
- 底部：「上一题」「下一题」（实测 `(545, 791)` / `(690, 791)`）。
- 实测 1699×888 选项行中心 y：题干单行时 A/B/C/D ≈ **292 / 352 / 410 / 467**；题干两行时 ≈ **317 / 377 / 435 / 493**。x 取 77（圆圈）或 300（行内文字）均可。
- 答题卡题号中心 x ≈ **1268 / 1318 / 1368 / 1427 / 1478**，y ≈ **311**（5 题时；题量变化重新量）。
- 该浮层 DOM 快照仍是 1 节点 → 全部靠截图。

## 第 6 页：结果页（提交后）

- 顶部：左返回箭头（约 `(57, 115)`）+ 知识点名。
