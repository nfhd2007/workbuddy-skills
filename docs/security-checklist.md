# 提交前安全检查清单

本仓库是**公开仓库**。任何进入 git 历史的内容都可能被爬走，删文件不等于删除历史。提交前逐项确认：

## 凭据类（禁止）

- [ ] 无 Cookie / SessionId / `Authorization` 头 / `Bearer` 值
- [ ] 无 API Key、Token、PAT（`ghp_`、`github_pat_`、`sk-`、`AKIA...`）
- [ ] 无私钥内容（`-----BEGIN ... PRIVATE KEY-----`）
- [ ] 脚本中没有硬编码 `password = "..."` / `api_key = "..."`
- [ ] 无 `.env`、`cookies.json`、`credentials.json`

## 个人与第三方数据（禁止）

- [ ] 无账号、学号、成绩、答题记录、题库、问卷答案
- [ ] 无浏览器用户数据、会话文件、含隐私的截图（截图常带用户名与页面内容）
- [ ] 脚本 / 文档中的本机绝对路径（`C:\Users\<name>\`、`/Users/<name>/`）已改成占位符或相对路径
- [ ] 未上传从技能市场安装的付费技能或他人作品原件；如需收录，已获授权并保留 `LICENSE` 与 `author`
- [ ] 技能若借鉴了第三方项目，已在文档中注明来源与许可证

## 产物与体积（禁止）

- [ ] 无 `node_modules/`、`__pycache__/`、`*.pyc`、`.venv/`
- [ ] 无 `*.zip` / `*.7z` 打包产物、`*.log`、`*.db`
- [ ] 单文件 ≤ 3 MB（与平台上架限制一致）

## 行为审查

- [ ] SKILL.md 说明了技能会做什么、会读写哪些文件、是否会联网
- [ ] `scripts/` 中没有未经说明的外部下载、上传或删除操作
- [ ] 破坏性操作（删除、覆盖、提交表单）已写明需要用户确认

## 自动检查

```bash
python scripts/validate_skills.py
```

脚本会扫描密钥格式、硬编码凭据、隐私数据文件名、禁止目录、文件体积与本机绝对路径。**通过不代表绝对安全，人工过一遍清单仍然必要。**

## 万一误提交了

1. 立刻撤销 / 轮换泄露的凭据（这一步最急，先做）。
2. 删除文件并提交只是第一步，还需清理 git 历史（`git filter-repo` 或 BFG）并强推。
3. 若已被 fork 或缓存，联系 GitHub Support 请求移除缓存视图。
4. 在 CHANGELOG 或 Issue 中记录事件，避免他人继续使用旧副本。
